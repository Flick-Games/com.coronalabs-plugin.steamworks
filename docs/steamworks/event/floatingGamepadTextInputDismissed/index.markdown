## Overview

This event occurs when the floating keyboard opened by [steamworks.showFloatingGamepadTextInput()][plugin.steamworks.showFloatingGamepadTextInput] is closed. It carries no data: the text has already been typed into the focused field.


## Properties

##### event.name
_[String][api.type.String]._ Always `"floatingGamepadTextInputDismissed"`.
